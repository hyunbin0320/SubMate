# 김영훈 담당 구현 요구사항

## 사용자

- 인증 회원은 판매 중인 상품을 가상 결제하고 구독을 시작한다.
- 회원 ID와 금액은 서버가 결정한다.
- 이용 기간이 남은 같은 상품을 중복 구독하지 않는다.
- 본인 구독·결제·환불만 조회한다.
- ACTIVE 구독을 해지하면 CANCELLED, 종료 시각까지 이용 가능하다.
- 종료일에 ACTIVE/CANCELLED는 EXPIRED가 된다.
- 만료 후 재구독은 새로운 Subscription을 생성한다.
- 결제당 한 번 전액 환불을 요청한다.

## 관리자

- 전체 구독 목록·상세 조회 및 해지를 처리한다.
- 전체 결제·환불 내역을 조회한다.
- REQUESTED 환불을 승인하거나 반려한다.
- 승인 시 환불·결제·구독을 일관되게 변경한다.

## 품질

- DTO와 Entity를 분리하고 Service에서 상태 전이를 처리한다.
- 트랜잭션·잠금·UNIQUE 제약으로 중복/부분 저장을 방지한다.
- 정상·오류·권한·날짜 경계·동시성 시나리오를 검증한다.
- API/DB 변경 및 팀 연결 규약을 문서화한다.
