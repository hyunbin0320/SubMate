# 검증 시나리오

## 자동 테스트 범위

SubscriptionFlowTests (실제 Service/Repository, H2, MockMvc):

- 정상 결제/구독 원자적 생성과 서버 가격
- 가상 결제 실패 데이터 미생성
- 강제 Payment INSERT 실패 시 Subscription까지 롤백
- 동일 키 재전송 및 다른 payload 충돌
- 같은 키 동시 요청 결제 1건, 다른 키 동시 요청 중복 구독 차단
- 비활성·없는 상품·0원 가격 거절, 입력/페이지 검증
- 비인증 401, 비관리자 403, 타인 상세/해지/환불 404
- 회원별 목록 데이터 격리
- 해지 후 이용 유지, 반복 해지·조기 재구독 거절
- 월말·윤년·연 구독 종료일
- 한국 시간 자정 ACTIVE/CANCELLED 만료, 반복 만료 멱등성
- 만료 후 새로운 구독 생성
- 관리자 목록/상세/해지
- 환불 승인 시 Refund/Payment/Subscription 일치 및 이용 종료
- 반려 후 결제·구독 유지, 재요청 거절
- FK로 참조된 회원/상품 삭제 차단

DemoSecurityTests: 실제 demo Basic 인증, 잘못된 비밀번호, 관리자 권한, loopback Origin의 POST 요청.
BackendApplicationTests: 일반 테스트 프로필 컨텍스트.

## 브라우저 시나리오

1. 일반 회원 로그인 → Cinema 신청 → 동의 → 가상 결제 → 완료 화면.
2. 구독 상세 이용 중 확인 → 해지 확인 → 해지 예약 + 이용 가능 유지 확인.
3. 결제 내역 → 환불 요청 사유 작성 → 접수 → 환불 내역 검토 중 확인.
4. 관리자 로그인 → 환불 관리 → 승인 → 완료.
5. 관리자 결제 REFUNDED, 구독 EXPIRED 확인.
6. 다른 회원 로그인 → 타인 데이터 없는지 확인.
7. 가상 결제 실패 시 오류 안내, 구독/결제 미생성 확인.
8. 모바일 크기에서 메뉴/폼 사용 가능 확인.

만료 검증은 실제 한 달을 기다리지 않고 Clock을 이동하는 자동 테스트로 수행합니다.
운영 API에 시간을 변경하는 기능은 추가하지 않았습니다.

## 한계

H2 MySQL 모드는 실제 MySQL과 동일하지 않습니다.
InnoDB 동시성·격리 수준·DDL과 실제 JWT 통합은 팀 환경에서 별도 검증해야 합니다.
